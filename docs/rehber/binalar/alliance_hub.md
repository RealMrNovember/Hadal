# İttifak Merkezi

`alliance_hub` · İttifak · 🟡

> İttifakla bağlantı istasyonu.

**İşlev.** İttifak yardımı: yardım sınırı 10 + ⌊seviye / 5⌋ (en fazla 20). Takviye kapasitesi. Reaktör önkoşul zincirindedir.
